# model-scoringowy-mintos
Przedstawione materiały dotyczą działań przeprowadzonych na danych w środowisku Jupyter Notebook z wykorzystaniem języka Python przed przejściem do budowy modelu scoringowego w programie Statistica. Wykorzystane dane pochodzą z platformy Mintos i dotyczą pożyczek społecznościowych oferowanych za jej pośrednictwem. 

Pracowano na trzech plikach:
- '1-500000_note_loan_book.xlsx'
- '500001-1000000_note_loan_book.xlsx'
- '1000001-1500000_note_loan_book.xlsx'

pobranych ze strony www.mintos.com

Pliki csv wczytywane w skryptach nie zostały załączone ze względu na prawa autorskie.
