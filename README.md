# model-scoringowy-mintos
Przedstawione materiały dotyczą działań, które wykonano z danymi w Pythonie (Jupyter Notebook) przed przejściem do budowy modelu scoringowego w programie Statistica. Wykorzystane dane pochodzą z platformy Mintos i dotyczą pożyczek społecznościowych. 

Pracowano na trzech plikach:
- '1-500000_note_loan_book.xlsx'
- '500001-1000000_note_loan_book.xlsx'
- '1000001-1500000_note_loan_book.xlsx'

pobranych ze strony www.mintos.com/en/set-of-notes/primary/.

Pliki csv wczytywane w skryptach nie zostały załączone ze względu na prawa autorskie.
